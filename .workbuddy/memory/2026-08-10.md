## 关键发现 / 取舍
- `Player.pickR` 是 getter，截图脚本不能用 `pickR=0`，改成 `Loot.pool.releaseAll()` + DOM 隐藏 + `setInterval` 守卫弹窗。
- 飞船白色剪影 vs 原色权衡：选白色剪影（霓虹统一染 + 受击可闪白），牺牲 Kenney 内部 cockpit 阴影，换取整体 synthwave 协调感。
- BOSS 保留 3D 母舰（多层环+炮塔+光晕），与 2D 飞船形成"舰群 vs 旗舰"对比，反而突出。

## 整体建模优化第二轮（用户："优化建模"）
- **玩家/僚机从扁平 Kenney 精灵 → 真 3D 组合模型**（用现成的 `Gfx.build`），敌人保留 Kenney（数量多、保性能、用户认可的画风）。
- `Gfx.build` 增加 `engine()` 辅助：每个机型尾部塞 `P.hub` 缩成 (0.5,0.4,0.4) 引擎块，给机体厚度与方向感；BOSS 是唯一独立建模不动。
- 朝向约定统一：**3D Group 朝向 +Z**，`group.rotation.y = yaw`；废弃 `Gfx.sHIP_ROT`（精灵路线专用）。
- 玩家 init 用 `Gfx.build('player').g` + `shipG.scale.setScalar(1.5)`；overdrive 的 `this.glow` 现在是 `shipG` 的子精灵，仍可变色。
- 僚机 add 用 `Gfx.build(type, t.color).g` + `shipG.scale.setScalar(1.4)`；列表对象字段 `ship` → `shipG`。
- BOSS `buildBoss` 新增第 4 层外环 `[8.6, 0.10, PI/2.6, 0xa78bfa, 0.32]`；`obj.rings[3].rotation.z -= dt*0.6`(进场) / `dt*0.25`(常态)，逆向慢转。
- 清理死代码 `WING_SPRITE` 常量。
